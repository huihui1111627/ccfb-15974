# 物理模型说明

## 1. 房间与网格

机房平面 46m × 23m,高 4m。离散为 1m×1m 网格。每排机柜 y 方向剖面(以南墙起):

```
j=0  南墙
j=1  南冷通道        ← 地板出风口送冷风
j=2  R1 机柜(正面朝南,从 j=1 取风,背面排到 j=3)
j=3  热通道          ← 顶部回风口抽回风
j=4  R2 机柜(正面朝北,从 j=5 取风)
j=5  冷通道(由 R2、R3 两排共享——面对面)
...
j=20 R10 机柜
j=21 北冷通道
j=22 北墙
```

空气网格分三类:冷通道(COLD)、热通道(HOT)、侧边通道(SIDE),外加空机柜位形成的缺口网格(GAP)。机柜本身不是空气网格,而是"取风-排风"元件。

## 2. 能量方程(每个空气网格)

稳态:

```
Σ_j h_ij (T_j − T_i)                       # 与相邻网格的风量交换
+ m_sup,i (T_sup,i − T_i)                  # 地板送风注入
+ m_ret,i (0   − T_i)                      # 回风抽出
+ Σ_cab m_cab (T_in,i − T_i)               # 机柜从该网格取风
+ h_wall (T_out − T_i) + h_amb (T_out − T_i)  # 墙体/渗透/环境锚
+ Q_i / (ρ cp)                             # 热源
= 0
```

离散后是线性方程组 `diag · T − Σ h_ij T_j = src`,用稀疏直接法求解(scipy)或红黑 SOR
(纯 NumPy 回退)。热惯性通过把上一时刻温度作为源项 `m_i/dt · T_prev` 加入,等效于每个
网格与"过去的自己"交换热量。

## 3. 机柜

- 风扇需求风量 `V_cab = v_base + v_kw · P`(与功率相关)。
- 冷通道地板送风给每个冷网格流量 `m_sup = f(空调风量, 风口开度)`,与机柜功率无关
  (地板砖送风量由空调和风口决定)。
- 机柜从正面冷网格取风 `V_cab`;若该网格可供冷风不足,机柜"缺风",进风掺入热通道
  顶部热风,进风温度向热通道温度靠近(热点主因之一)。
- 出风温度 `T_out = T_in + P/(ρ cp V_cab)`,排入背面热网格。
- 缺口(空机柜位):GAP 网格以 `gap_flow` 连接冷热通道,热风经缺口回流污染冷通道。

## 4. 空调(精密空调)

- 控制量:送风温度设定 `T_set`、风机风量比 `f`。
- 一阶响应:`x ← x + (1 − e^{−Δt/τ})(x_cmd − x)`,τ 为送风温度/风量时间常数。
- 启停延迟:指令变化后需 `DELAY_START/DELAY_STOP` 分钟建立/撤销风量与制冷。
- 制冷量 `Q = ρ cp V (T_ret − T_set)`,受 `Q_MAX` 与 `T_SUP_MIN`(露点保护)约束。
- 功率 `P = fan(f) + Q/COP(T_set, T_out)·(1+管网损失) + Q·水泵系数`;
  COP 随送风温度升高而升高、随室外温度升高而降低。

## 5. 数字孪生与校准

控制器用一份"数字孪生"模型做预测,其参数起初偏离真值。周期性:

1. **状态校正**:把孪生在各传感器位置的温度拉向实测读数(简单观测更新)。
2. **参数校准**:以有限差分雅可比 + Levenberg-Marquardt,最小化"孪生预测的进风温度 −
   传感器读数"的残差,更新 `gap_flow, recirc, v_kw, h_wall` 等可辨识参数(带物理边界)。

校准的好处见 `results/calibration.json`:RMSE 从约 2K 降到约 0.6K,`v_kw`、`gap_flow`
逐步逼近真值。
